# Essais de diagnostic sur IHU007B

Cette procédure concerne uniquement l’APK française de diagnostic, sans écriture automobile et sans modification du firmware. Les effets Android et les lectures ECARX n’ont pas encore été vérifiés sur votre tablette.

1. Copier l’APK depuis la branche de diagnostic, vérifier son SHA-256 dans le rapport et l’installer avec l’installateur Android habituel. Son paquet distinct `com.aztech.jarvisfr.reconstruction` permet de conserver le Jarvis russe. Il s’agit d’une signature de diagnostic ; une reconstruction sur une autre machine peut avoir un certificat différent.
2. Ouvrir **Jarvis FR Diagnostic** et attendre le statut du modèle. Le premier lancement copie le modèle de 65,31 Mio dans le stockage privé de l’application. Noter le message exact si le modèle échoue à charger.
3. Commencer par la saisie : « pause », « piste suivante », « ouvre la navigation », « ouvre le téléphone », « ouvre le navigateur internet ». Les demandes médias peuvent modifier la lecture en cours ; le téléphone ouvre uniquement le composeur. Vérifier l’effet constaté, sans déduire le succès du seul message de demande transmise.
4. Autoriser le microphone, puis appuyer de nouveau sur **Écouter en français**. Prononcer une seule commande. Chaque écoute dure au maximum 15 secondes. Relever séparément la phrase réellement affichée, l’intention et l’effet observé. Le vocabulaire guidé est limité ; le décocher permet d’essayer le mode libre. Un faux positif guidé a été observé sur une phrase hors domaine dans les essais synthétiques.
5. Contrôler l’arrêt à la sortie de l’écran, le refus d’autorisation, le délai sans parole, l’arrêt manuel et plusieurs activations successives. Le microphone ne redémarre pas automatiquement. La synthèse exige un moteur TTS doté de données françaises ; l’application signale leur absence.
6. Tester les boutons de lecture brute de l’autonomie et du compresseur A/C. Conserver le statut de support et le détail de l’erreur. « Indisponible » ne signifie pas zéro. Comparer toute valeur brute aux états affichés par la voiture avant d’attribuer une unité ou un sens.
7. Confirmer que « allume la climatisation », « règle la température à vingt deux degrés », « ventilation niveau trois » et « ouvre la vitre » ne font qu’afficher une désactivation. Les variantes négatives ou composites doivent être rejetées.

Pour un diagnostic technique avec les outils Android déjà accessibles, relever le paquet, le message affiché et un logcat ciblé sur le processus de l’application. Il n’est pas nécessaire d’activer une connexion ADB permanente, d’accorder des permissions système, de rooter la tablette ou de modifier son firmware. Si les classes ECARX sont introuvables, relever la liste des bibliothèques partagées du système avant tout changement du manifeste ; le nom de package Java ne prouve pas le nom d’une bibliothèque.

Compte rendu conseillé pour chaque essai : version APK et modèle de tablette, phrase prononcée/saisie, texte Vosk affiché, message de l’application, résultat visible réel et éventuelle erreur. Une commande physique ne pourra être déclarée compatible qu’après une validation indépendante, fonction par fonction, dans une version ultérieure expressément autorisée.
